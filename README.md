# Ishabella Corp Website

Next.js + TypeScript + GSAP cinematic corporate landing page.

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Assets
- `public/logo.png` is the logo supplied in chat.
- **Hero image is intentionally not yet generated.** Add your aerial rooftop solar installation photo as `public/hero-solar.jpg`. The hero currently uses a dark green gradient fallback.
- Replace text-only brand placeholders with licensed official brand logos before launch.

## Sections
Hero, About, Our Story timeline, Solutions, Brand Network, Contact.

Company details are adapted from the supplied Ishabella company profile. Verify public-facing claims and contact details before deployment.
